2. IMU 原始輸出格式（YESENSE 二進位協議）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

硬體資訊：
  - 型號：WHEELTEC H30 Mini
  - 晶片：YIS106（YESENSE）
  - 接口：USB → CH9102 虛擬串口（COM4）
  - 波特率：460800 bps（預設，非 115200！）

Frame 格式（二進位 Little-Endian）：
  ┌──────┬──────┬───────────┬─────┬─────────────────┬──────┬──────┐
  │ 0x59 │ 0x53 │ TID(2 B)  │ LEN │ Payload (N bytes)│ CK1  │ CK2  │
  │  'Y' │  'S' │ 幀序號    │ 1B  │ TLV 格式資料    │ 校驗 │ 校驗 │
  └──────┴──────┴───────────┴─────┴─────────────────┴──────┴──────┘
  最短 7 bytes，總長 = 7 + LEN bytes

Payload 使用 TLV 格式（Type + Length + Value）：
  Type  | Length | 內容              | 物理單位        | 換算因子
  ─────────────────────────────────────────────────────────────────
  0x01  | 2      | 溫度              | °C              | × 0.01
  0x10  | 12     | 加速度 acc_x/y/z  | m/s²            | × 1e-6
  0x20  | 12     | 角速度 gyro_x/y/z | rad/s           | × 1e-6
  0x40  | 12     | 尤拉角 pitch/roll/yaw | 度(°)       | × 1e-6
  0x41  | 16     | 四元數 q0/q1/q2/q3 | 無單位[-1,1]  | × 1e-6
  0x80  | 1      | 融合狀態          | 旗標            | —

四元數慣例：
  q0 = qw（標量）, q1 = qx, q2 = qy, q3 = qz
  → Hamilton 慣例（qw 在前），與 MuJoCo 相同 ✓

3. 機器人 Actor 需要什麼（觀測向量第 22–31 維）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

觀測向量（共 31 維）中 IMU 相關欄位：

  Index   | 名稱             | 維度 | 訓練單位         | 訓練噪聲
  ──────────────────────────────────────────────────────────────────
  [22:25] | projected_gravity | 3   | 無單位（重力方向） | 訓練中加
  [25:28] | imu_acc           | 3   | m/s²（含重力）   | ± 1.0 m/s²
  [28:31] | imu_gyro          | 3   | rad/s            | ± 10°/s

注意：
  - projected_gravity 是「最重要」的欄位，代表機器人的姿態傾斜方向
  - imu_acc 直接輸出（包含重力，不做補償），站直時 z 軸 ≈ +9.81
  - imu_gyro 直接輸出角速度

4. 轉換流程（IMU 原始 → 機器人觀測向量）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Step 1：解析 YESENSE 二進位 frame（由 read_imu.py 完成）
         raw_int → × 1e-6 → 物理值

Step 2：imu_acc（直接使用）
         imu_acc = [acc_x, acc_y, acc_z]  單位 m/s²
         站直靜止時應約為 [0, 0, +9.81]（z 朝上）
         ⚠ 若重力出現在其他軸，表示 IMU 安裝方向與模擬不同，需旋轉座標系

Step 3：imu_gyro（直接使用）
         imu_gyro = [gyro_x, gyro_y, gyro_z]  單位 rad/s
         靜止時應接近 [0, 0, 0]

Step 4：projected_gravity（需計算）
         從四元數 [qw, qx, qy, qz] 計算：

         qw, qx, qy, qz = IMU 輸出的 q0, q1, q2, q3

         # 旋轉矩陣 R（body→world）的第三列
         R02 = 2*(qx*qz + qy*qw)
         R12 = 2*(qy*qz - qx*qw)
         R22 = 1 - 2*(qx*qx + qy*qy)

         # 世界重力 [0, 0, -9.81] 轉到機身座標系
         proj_gravity = R.T @ [0, 0, -9.81]
                      = (-9.81*R02, -9.81*R12, -9.81*R22)

         站直靜止時 ≈ [0, 0, -9.81]（重力沿機身 -z 方向）

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
5. 確認清單（驗證 IMU 與模擬對齊）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  □ imu_acc 靜止時哪個軸接近 ±9.81？
      → 如果是 z 軸（acc_z ≈ +9.81）：與模擬對齊 ✓
      → 如果是其他軸：IMU 安裝方向不同，需要額外座標旋轉

  □ |imu_acc| ≈ 9.81（向量長度）？
      → 驗證加速度計工作正常

  □ imu_gyro 靜止時 ≈ [0, 0, 0]？
      → 驗證陀螺儀無偏移

  □ |quaternion| ≈ 1.0（模長）？
      → 驗證姿態融合正常運作

  □ projected_gravity 靜止時 ≈ [0, 0, -9.81]？
      → 驗證重力投影計算正確
